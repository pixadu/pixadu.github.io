# Pixadu

Pixadu is a modern browser gaming platform developed by **Deepak Sharma**.

## Founder & Developer

**Deepak Sharma** is the founder and developer of Pixadu.

Pixadu was created to provide a modern and accessible browser gaming experience where players can play games directly online.

## 🌐 Website

https://pixadu.github.io/

## 🎮 About Pixadu

Pixadu features browser-based gaming across:

- 3D Games
- Arcade Games
- PC Games

The platform is built using modern web technologies including HTML, CSS and JavaScript.
